# Custom household noise recordings

Drop your own recordings here (e.g. from a Mumbai home). Any sample rate / WAV, FLAC or MP3; they are
resampled to 8 kHz mono automatically.

Put each noise type in its own subfolder so results can be reported per category:

    ceiling_fan/  ac_hum/  traffic/  tv_speech/  pressure_cooker/  kitchen/  other/

Tips: record 1–5 min per file, with no mosquitoes in the room, using the phone or microphone you
plan to deploy. Note the device and room in the filename, e.g. `ceiling_fan/bedroom_pixel7_speed3.wav`.
